# User docs

This directory is the operational reference for the use of aelfrice.

- [`QUICKSTART.md`](QUICKSTART.md) — the shortest procedure from the installation to the first locked belief.
- [`INSTALL.md`](INSTALL.md) — the installation paths, the optional extras and the hooks that are on by default.
- [`COMMANDS.md`](COMMANDS.md) — the full reference for the `aelf` command-line interface.
- [`SLASH_COMMANDS.md`](SLASH_COMMANDS.md) — the `/aelf:*` slash commands.
- [`CONFIG.md`](CONFIG.md) — the reference for the `.aelfrice.toml` file.
- [`PRIVACY.md`](PRIVACY.md) — the data that stays local, and the data that does not.
- [`LIMITATIONS.md`](LIMITATIONS.md) — the known limits and the behaviour that can surprise you, listed by version.
