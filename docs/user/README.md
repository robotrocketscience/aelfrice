# User docs

This directory is the operational reference for using aelfrice.

- [`QUICKSTART.md`](QUICKSTART.md) — the shortest procedure from installation to your first locked belief.
- [`INSTALL.md`](INSTALL.md) — installation paths, optional extras, and hooks that are on by default.
- [`COMMANDS.md`](COMMANDS.md) — the full reference for the `aelf` command-line interface.
- [`SLASH_COMMANDS.md`](SLASH_COMMANDS.md) — the `/aelf:*` slash commands.
- [`CONFIG.md`](CONFIG.md) — the reference for the `.aelfrice.toml` file.
- [`PRIVACY.md`](PRIVACY.md) — what data stays local, and what data doesn't.
- [`LIMITATIONS.md`](LIMITATIONS.md) — known limits and behavior that can surprise you, listed by version.
