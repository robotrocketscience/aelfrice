### Internal

- **The search-tool and agent-context hooks no longer carry a payload-`cwd` branch that could never run ([#1701](https://github.com/robotrocketscience/aelfrice/issues/1701)).** Both hooks read the payload `cwd` and passed it to `db_path(cwd=...)` behind a signature probe, but `db_path()` takes no `cwd`, so the probe was always false and both always used the hook process's cwd. The probe and the unused `cwd` read are gone, and a comment states the rule [#1630](https://github.com/robotrocketscience/aelfrice/issues/1630) settled: the store resolves from the process cwd, which the host sets to the session's directory. `tests/test_hook_process_cwd_store_1701.py` gives each hook a payload `cwd` in another repository and fails if a hook reads that repository's store. Behavior is unchanged.
