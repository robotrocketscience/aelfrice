### Internal

- **`aelfrice.hook` is no longer in an import cycle ([#1631](https://github.com/robotrocketscience/aelfrice/issues/1631)).** Run `scripts/import_cycles.py` to list every import cycle in the package. The script builds the first-party import graph from the source, counts imports at every scope, and prints each strongly connected component of two or more modules. Before this change it reported a five-module component: `cli`, `doctor`, `hook`, `hook_search_tool`, and `provenance_render`. Every edge in that component was a function-local import, so nothing failed when the package loaded. Inside the component, `doctor`, `hook_search_tool`, and `provenance_render` each imported from `aelfrice.hook`, through five import statements in all, and those statements are gone now. The two render-time escapers moved to the leaf module `aelfrice.hook_payload`, so `provenance_render` and the search hook no longer import `aelfrice.hook`. The `[memory_block]` switch and the `UserPromptSubmit` telemetry reader moved to `aelfrice.hook_audit`, so `aelf doctor` no longer imports `aelfrice.hook`. `aelfrice.hook` still exports every moved public name, so existing `from aelfrice.hook import ...` callers keep working, and `tests/test_hook_reexports_1631.py` pins that. The private names it no longer uses itself, `_escape_attr` and the three helpers behind the switch, are not re-exported; import `escape_attr` from `aelfrice.hook_payload`. Both leaf modules were already in the hook's import closure, so `import aelfrice.hook` loads the same set of modules as before. The script now reports three cycles of two modules each: `bfs_multihop` and `edge_rerank`, `context_rebuilder` and `working_state`, and `expansion_gate` and `retrieval`. This change doesn't touch them. The script doesn't draw edges built with `importlib.import_module`, such as the hook's lazy loader for its retrieval names. `tests/test_import_cycles_1631.py` reads the whole graph and fails if any cycle contains `aelfrice.hook`. Putting back any one of the five removed imports makes that test fail.
