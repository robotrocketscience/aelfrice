### Added

- **Transcript ingest can log reworded restatements as unapplied SUPPORTS matches ([#1650](https://github.com/robotrocketscience/aelfrice/issues/1650)).** A new setting, `[ingest] log_reworded_support` (environment variable `AELFRICE_LOG_REWORDED_SUPPORT`), is off by default. When you turn it on, each sentence you type in a transcript is checked against beliefs that are not yours and were not created in the same session, and each reworded restatement is recorded in `belief_support_evidence` with `applied` set to 0. It only logs: it writes no `SUPPORTS` edge, changes no confidence, and records no feedback. Each sentence is checked against at most 20 candidates, and a failure in the check never fails ingest. `aelf doctor` shows how many matches are logged when the setting is on. The posterior-channel audit lists the setting with its default.
