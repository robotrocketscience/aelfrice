### Fixed

- **`aelf setup` names the onboard command for your host ([#1859](https://github.com/robotrocketscience/aelfrice/issues/1859)).** The next-step line named `aelf onboard .`, the terminal command that uses the regex classifier, while the README sends you to `/aelf:onboard .` in your agent, which classifies with the agent's model. The line now names `/aelf:onboard .` on the `claude` host. `aelf setup --host codex` printed no next step, and now names `$aelf-onboard .`, or `aelf onboard .` when that skill isn't installed. From a folder with no git work tree and no `[store]` marker, the line no longer says "this project" and tells you to open a project first. A folder with a `[store]` marker has its own store, so it gets the project line without git. With `--project-root`, the line describes that folder. The line still prints only when the store is empty, and it prints nothing when the store can't be read or git gives no answer about the folder. Reading the count writes nothing to the store.
