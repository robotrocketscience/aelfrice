### Added

- **The core admission gate's classifier rubric and prompt ship in `aelfrice.core_gate` ([#1638](https://github.com/robotrocketscience/aelfrice/issues/1638)).** The module holds the A, B, and C rubric that labels a core candidate as a self-contained claim, a claim that needs context, or not a claim. It also holds the batch prompt the host runs and a strict parser for the reply. The definitions and decision rules are the ones the reference raters used, word for word. Only the examples are new. `CLASSIFIER_VERSION` is derived from a digest of the assembled prompt, the label set, the batch limit, the model tier, and the source of the prompt builder and the reply parser. Any change to them is a new version, and cached labels from the old one stop applying, with nothing to bump by hand. A test pins the current digest so such a change is deliberate. The parser rejects a reply as a whole unless it labels every snippet in the batch exactly once, so a failed run can't pass for labels. Nothing calls the module yet: the label cache, core selection, and the session-end batch come next.
