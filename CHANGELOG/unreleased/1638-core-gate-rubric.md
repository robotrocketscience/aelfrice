### Added

- **The core admission gate's classifier rubric and prompt ship in `aelfrice.core_gate` ([#1638](https://github.com/robotrocketscience/aelfrice/issues/1638)).** The module holds the A, B, and C rubric that labels a core candidate as a self-contained claim, a claim that needs context, or not a claim. It also holds the batch prompt the host runs and a strict parser for the reply. The definitions and decision rules are the ones the reference raters used, word for word. Only the examples are new. `CLASSIFIER_VERSION` names the classifier, and the tests pin one digest of the assembled prompt, batch limit, and model tier per version, so changing any of them fails a test until you add a new version. The parser rejects a reply as a whole unless it labels every snippet in the batch exactly once, so a failed run can't pass for labels. Nothing calls the module yet: the label cache, core selection, and the session-end batch come next.
