### Fixed

- **After `turns.jsonl` starts over, the Stop-time transcript ingest runs once the new file reaches the threshold ([#1726](https://github.com/robotrocketscience/aelfrice/issues/1726)).** A compaction moves `turns.jsonl` to the archive and starts a new, empty file. The counter of turns at the last ingest kept its old value. The Stop check treated a smaller count as a reset but never saved it. When the old value equaled the threshold, the reset was forgotten as soon as the new file grew back to that value, and the next ingest waited until the file reached twice the threshold: 24 turn lines instead of 12 at the default. Compaction now resets the counter to 0. A Stop that counts fewer lines than the counter now saves the reset too, so a file you delete, or a counter left over from before this fix, also gets the usual schedule. You control the Stop-time ingest with `AELFRICE_INGEST_STOP_FLUSH_TURNS`.
