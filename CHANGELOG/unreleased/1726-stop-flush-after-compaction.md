### Fixed

- **After a compaction, the Stop-time transcript ingest runs once the new `turns.jsonl` reaches the threshold ([#1726](https://github.com/robotrocketscience/aelfrice/issues/1726)).** A compaction moves `turns.jsonl` to the archive and starts a new, empty file. The counter of turns at the last ingest kept its old value. The Stop check treated a smaller count as a reset but never saved it, so the reset was forgotten once the new file grew back to the old value. When the old value was at or below the threshold, the next ingest waited until the file reached the old value plus the threshold: 24 turn lines instead of 12 at the default. Compaction now resets the counter to 0, and a Stop that counts fewer lines than the counter saves the reset. If you delete `turns.jsonl`, the usual schedule also applies, provided a Stop runs before the file grows back to the old count. You control the Stop-time ingest with `AELFRICE_INGEST_STOP_FLUSH_TURNS`.
