### Fixed

- **After a compaction, the Stop-time transcript ingest runs once the new `turns.jsonl` reaches the threshold ([#1726](https://github.com/robotrocketscience/aelfrice/issues/1726)).** A compaction moves `turns.jsonl` to the archive and starts a new, empty file. The counter of turns at the last ingest stored only a count, so it carried over to the new file. The Stop check treated a smaller count as a reset but never saved it, so the reset was forgotten once the new file grew back to the old value. When the old value was at or below the threshold, the next ingest waited until the file reached the old value plus the threshold: 24 turn lines instead of 12 at the default. The counter now also records which file it counted, by inode, and a counter for any other file counts as 0. That covers a compaction, a Stop that writes its count just after the rotation, and a deleted file, unless the filesystem gives the new file the deleted file's inode. A counter written before this release holds only a count, so it is treated the same way, and the first Stop after you upgrade may run one extra ingest. Ingest skips statements it already stored. You control the Stop-time ingest with `AELFRICE_INGEST_STOP_FLUSH_TURNS`.
