### Added

- **A transcript belief now anchors to the turn it came from, not to its source label ([#1602](https://github.com/robotrocketscience/aelfrice/issues/1602)).** Every transcript anchor used to be `file:<source label>`. The labels in use are a few constants, so an anchor recorded that some transcript existed without naming which part of it a belief came from. When a turn is ingested with both a session id and its own timestamp, each sentence's belief now anchors to `file:<label>#<session_id>/<ts>/<turn_sha>`. That covers `aelf ingest-transcript`, the transcript-log flush, and a direct `ingest_turn(..., session_id=..., created_at=...)` call. `turn_sha` is the first 16 hex characters of the SHA-256 of the whole turn text, and the same fragment is stored as the anchor's `position_hint`. The label stays the URI's prefix, so a consumer that groups anchors by source still can. The anchor is provenance, not a truth check: with the transcript at hand, a reader can tell whether a turn still says what it said at ingest, but nothing adjudicates the belief itself. For each ingest row, the writer produces the turn anchor instead of the label-only one, never both. A belief asserted in several turns gets one anchor per turn, and re-ingesting the same file writes no second row. A turn with no timestamp of its own still gets the label-only anchor, because ingest fills that timestamp from the clock, and a re-ingest would then get a different anchor. `derive()` never reads the fingerprint, so replay equality does not depend on it. There is no backfill: existing label-only anchors stay, so a belief that already had one keeps it alongside any turn anchors that later corroborations add. `scripts/turn_anchor_census.py` counts transcript rows, turns, and reachable beliefs, and how many anchors are turn or label-only. On a store written before this change, its turn count is an upper bound, because nothing on an old row records whether its timestamp came from the clock. `DerivationInput.raw_meta` is now typed `dict[str, object] | None`, which lowers the pyright baseline from 972 to 965.
