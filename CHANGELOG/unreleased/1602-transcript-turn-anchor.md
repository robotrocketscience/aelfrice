### Added

- **A transcript belief now anchors to the turn it came from, not to its source label ([#1602](https://github.com/robotrocketscience/aelfrice/issues/1602)).** Every transcript anchor used to be `file:<source label>`. The labels in use are a few constants, so an anchor recorded that some transcript existed without naming which part of it a belief came from. When `aelf ingest-transcript` reads a turn that carries both a session id and its own timestamp, each sentence's belief now anchors to `file:<label>#<session_id>/<ts>/<turn_sha>`. `turn_sha` is the first 16 hex characters of the SHA-256 of the whole turn, and the same fragment is stored as the anchor's `position_hint`. The label stays the URI's prefix, so a consumer that groups anchors by source still can. The anchor is provenance, not a truth check: with the transcript at hand, a reader can tell whether a turn still says what it said at ingest, but nothing adjudicates the belief itself. The new anchor replaces the label-only one rather than sitting beside it. A belief asserted in several turns gets one anchor per turn, and re-ingesting the same file writes no second row. A turn with no timestamp of its own keeps the label-only anchor, because ingest fills that timestamp from the clock, and a re-ingest would then get a different anchor. `derive()` never reads the fingerprint, so replay equality does not depend on it. Existing beliefs keep their label-only anchors; there is no backfill. `scripts/turn_anchor_census.py` reports how many transcript rows and beliefs a store's turn anchors reach. `DerivationInput.raw_meta` is now typed `dict[str, object] | None`, which lowers the pyright baseline from 972 to 965.
