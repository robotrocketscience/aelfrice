### Documentation

- **The documented developer setup now installs the extras it needs, so a local green is the green that gates the merge ([#1548](https://github.com/robotrocketscience/aelfrice/issues/1548)).** `CONTRIBUTING.md` § Development setup told a contributor to run `uv sync --all-groups`. That installs dependency **groups**, and `archive` is an **extra** (`cryptography>=50.0`, `[project.optional-dependencies]`), so the documented command left `cryptography` uninstalled and two things went quietly wrong. Eight tests skipped — `test_uninstall_archive_roundtrip`, `test_uninstall_archive_wrong_password_rejected`, `test_archive_gate_says_the_extras_are_deleted_not_encrypted`, `test_archive_of_a_live_store_recovers_every_belief`, `test_archive_removes_the_derived_plaintext_artifacts`, `test_archive_destination_inside_the_store_dir_is_not_deleted`, `test_cli_removes_consent_in_every_disposition_mode[archive]` and `test_cli_archive_gate_discloses_the_dotdir_paths` — and they cover the one path where a bug destroys data a user asked to keep, so a contributor touching `lifecycle.py` under the documented setup got a green suite that never exercised it. Measured on the four modules: **130 passed with the extra, 122 passed and 8 skipped without it**. And `pyright` could not resolve `cryptography.fernet` or `cryptography.hazmat` in `src/aelfrice/lifecycle.py`, so a cascade of unknown types pushed that file from **31 errors to 54** and `scripts/check_pyright_baseline.py` failed on a correctly set-up machine for a reason that was not in the diff. That file is the **whole** per-file difference between the two environments — a full `pyright src/` run gives 973 errors over 75 files with the extras and 996 without, and no other file moves by one — so the phantom 23 was the entire gap. CI never saw it, because `pyright-ratchet.yml` syncs `--all-extras` and `ci.yml`'s `pytest` job syncs `--group dev --extra archive`. Both `CONTRIBUTING.md` and `RELEASING.md` step 6 now sync `--all-groups --all-extras`, which covers the strongest of the workflows, and both say why. A skip caused by a missing optional dependency also has to name the extra rather than the import: the eight gates share one `requires_archive_extra()` helper in `tests/conftest.py` whose reason reads "requires the 'archive' extra: uv sync --all-groups --all-extras", and `pytest_terminal_summary` reports the count in an `optional extras` section, so the skips are visible in the tail and not only under `-rs` — the same shape the bench-gate tier already used, and for the same reason, that a skip deletes coverage as quietly as a failure blocks work. The drift is what `tests/test_documented_setup_1548.py` prevents from recurring: it parses the `uv sync` line out of the setup block and out of `ci.yml`'s `pytest` job and `pyright-ratchet.yml`'s `ratchet` job, and fails when the documentation installs less than either, so an extra added to a workflow and not to the documentation is a red test rather than a silent gap. It parses by line rather than with PyYAML, because `yaml` is not in the dependency set CI syncs and an `import yaml` there passes locally and fails on the runner; the parser is small enough to be wrong quietly, so its shape is pinned directly against the three `uv sync` spellings the workflows use. Whether `archive` should be a group rather than an extra is out of scope and unchanged — it is optional because `cryptography` is heavy and the feature is opt-in.
