### Fixed

- **An edge never links a belief to itself any more ([#1636](https://github.com/robotrocketscience/aelfrice/issues/1636)).** `ingest_jsonl` chains each user turn to the previous one with a `DERIVED_FROM` edge, anchored on the belief each turn resolved to. A turn that repeats the one before it resolves to the same belief, so the writer stored an edge from that belief to itself. On a synthetic session of 500 distinct turns plus 50 duplicates in 45 runs, it stored 45 such self-loops. `MemoryStore.insert_edge` now refuses an edge whose two ends are the same belief, for every caller. It returns `False` instead of raising, because hooks call it, and returns `True` when it writes. Most writers already avoided self-loops with their own check. The ingest inter-turn writer, `contradiction.resolve_contradiction`, and `aelf migrate`, which copies a legacy store's edges, did not. Those three now count only the edges actually written. A session of A, B, B, C links C to B and B to A. The chain still advances past the skipped edge, so the next edge's anchor carries the later turn's text. `find_unresolved_contradictions` no longer lists a belief paired with itself. Such a legacy row can never be settled, and before this change it would have been re-resolved, with an audit row, on every run. Existing self-loops in a store are left in place, and `aelf migrate` does not copy them.
