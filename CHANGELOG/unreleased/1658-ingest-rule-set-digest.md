### Added

- **Each new `ingest_log` row records the classifier rules it was written under, and `aelf doctor` counts the rows that differ ([#1658](https://github.com/robotrocketscience/aelfrice/issues/1658)).**
  - **Before:** `ingest_log.classifier_version` and `ingest_log.rule_set_hash` were NULL on every row, because no production writer passed them.
  - **Now:** all six production `record_ingest` calls stamp `classifier_version` with the new `classification_core.INGEST_CLASSIFIER_VERSION` and `rule_set_hash` with `classification_core.rule_set_hash()`. The digest is a sha256 over canonical JSON of the `classify_sentence` keyword and pattern tables, its priors, the correction detector's tables, and the LLM classifier's system prompt and user-message format. It hashes the tables as data rather than source text, so it works on a bytecode-only install, is computed once per process, and is NULL when an input cannot be loaded. `aelf doctor` adds an informational `ingest log rule set` section with one read-only query: total rows, rows with a different digest, and rows with none.
  - **Limits:** rows written before this change stay NULL, since nothing records which rules wrote them. `derive()` and replay do not read either column, so a rebuild still applies the current rules to every row. `INGEST_CLASSIFIER_VERSION` is not `core_gate.CLASSIFIER_VERSION` from [#1638](https://github.com/robotrocketscience/aelfrice/issues/1638), which versions a classifier that runs after ingest.
