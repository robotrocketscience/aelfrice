### Fixed

- **The docs and help text name the search-tool hook's current matcher, and one tuple now defines it ([#1628](https://github.com/robotrocketscience/aelfrice/issues/1628)).** [#1626](https://github.com/robotrocketscience/aelfrice/issues/1626) widened the matcher from `Grep|Glob` to `Grep|Glob|WebSearch|WebFetch`, but `ARCHITECTURE.md`, `INSTALL.md`, `COMMANDS.md`, the `/aelf:setup` command page, the `--search-tool` help for `aelf setup` and `aelf unsetup`, the hook manifest description, and a `setup.py` docstring about uninstall still gave the old value. They now name all four tools. `docs/design/search_tool_hook.md` gets a dated note instead of a rewrite, because its body records the v1.2.x and v1.5.0 design as it shipped. The roadmap and earlier changelog entries are history and stay as written. **The matcher and the hook's tool set are one fact again.** `SEARCH_TOOL_NAMES` and `SEARCH_TOOL_MATCHER` were two hand-kept copies. Both now live in the leaf module `aelfrice.search_tool_names`, and the matcher is the `|`-join of the names. It's a leaf rather than a direct import: `setup` importing `hook_search_tool` would grow the import cycle through `aelfrice.hook` ([#1631](https://github.com/robotrocketscience/aelfrice/issues/1631)) from 5 modules to 8, and the reverse would load the installer on every hook fire. `import aelfrice.hook` still loads 19 aelfrice modules, and the import graph's strongly connected components are unchanged. Importing `aelfrice.hook_search_tool` or `aelfrice.setup` directly loads one more module, the new leaf, which imports only `typing`. **A guard keeps the prose in step.** A new test reads each live page that states the matcher and fails when it disagrees with `SEARCH_TOOL_MATCHER`, so the next widening can't leave the docs behind. The fixture in `test_setup_prune_stale.py` that transcribed `"Grep|Glob"` for a current install now reads the constant; the `test_doctor.py` fixture that models a legacy shell-wrapper install keeps the old value, with a comment saying why. No behavior changes.
