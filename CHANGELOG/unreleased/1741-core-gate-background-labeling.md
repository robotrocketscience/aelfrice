### Added

- **Core candidates are labeled in the background, with nothing added to your conversation ([#1741](https://github.com/robotrocketscience/aelfrice/issues/1741)).** When the Stop hook finds the session's new core candidates and the `claude` CLI is on your `PATH`, it records a batch of up to 50 and starts a detached process. That process runs `claude -p` on its smallest model with your `claude` login, with no tools, MCP servers, skills, CLAUDE.md, auto memory, or hooks, and with a $0.10 cap per run. It then caches the labels the way `aelf core-gate accept` does. The Stop isn't slowed down.
  - **Measured:** on a 519-item reference set, the labels agree with the two-rater reference 83.2% of the time, against 83.0% for the earlier smallest-tier labeling. A 50-belief batch costs about $0.04.
  - **Credentials:** the run's environment drops `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN`, because in `-p` mode a set key always wins over the login, and the run loads none of your user, project, or local `claude` settings, so an `apiKeyHelper` isn't used either. If you use only an API key, every background run fails and leaves its batch open; set `[core_gate] background = false` to stop them.
  - **The classifier version changes once:** `parse_labels` now accepts a reply wrapped in one Markdown code fence, for `aelf core-gate accept` too. Labels made under 5.1.x no longer apply: those beliefs count as unlabeled, so one labeled C returns to core. Background labeling covers each session's new beliefs only; to label older ones again, run `aelf doctor core-gate --emit`.
  - **What leaves the machine:** the text of the batched beliefs, to the model behind your `claude` login. [Privacy](../docs/user/PRIVACY.md) lists it as the third outbound path that's on by default.
  - **To turn it off:** set `[core_gate] background = false` or `AELFRICE_CORE_GATE_BACKGROUND=0`. With it off, or without `claude` on your `PATH`, the #1740 opt-in turn applies if you turned it on. It doesn't run on Windows yet, in headless sessions, or on the Codex host.
  - **Diagnostics:** each run appends one line, with no belief text, to `core_gate_background.jsonl` beside the store. A run that fails leaves its batch open, and `aelf doctor core-gate --emit` batches those beliefs again. If the process can't be started, the Stop hook also writes one line to stderr.
