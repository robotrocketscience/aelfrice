### Added

- **`aelf doctor --gc-filesystem-corroboration` removes the corroboration rows that re-onboarding wrote before #1615 ([#1669](https://github.com/robotrocketscience/aelfrice/issues/1669)).** A store that was onboarded or scanned more than once before [#1615](https://github.com/robotrocketscience/aelfrice/issues/1615) still holds a corroboration row for every paragraph each rescan read again, and those rows still count toward `aelf core` and the `corr=` value on injected beliefs. The command reports how many rows there are, how many beliefs they sit on, and which beliefs would leave `aelf core` without them. It changes nothing unless you add `--apply`, which deletes those rows and leaves every other source's rows as they are. The dry run measures the core change by running the delete and rolling it back, so it reports what `--apply` would do, not an estimate.
