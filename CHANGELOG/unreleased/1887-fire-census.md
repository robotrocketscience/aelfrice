### Internal

- **A fire census reports which features have fired in copies of your stores ([#1887](https://github.com/robotrocketscience/aelfrice/issues/1887)).** `python -m benchmarks.real_store_fire_census` runs one read-only probe per feature on `main` and reports `fired`, `silent` or `untraceable` for each store, with integer counts only. It reads copies, never live stores: it refuses a path inside a `.git` folder or under `~/.aelfrice`, and it opens each `memory.db` with `mode=ro` and `immutable=1`, so it changes no byte beside the store. `python -m benchmarks.real_store_fire_census.copy_store` copies a store folder with its `-wal` and `-shm` files and folds the WAL into the copy. Stores appear in the output as opaque labels such as `store01`; the map from labels to paths is written only to the file that you name with `--labels-out`, which must sit outside the repository. Tests build a store with aelfrice's own code for each probe and check that it reports `fired` when the feature runs and `silent` on an empty store. `benchmarks/real_store_fire_census/README.md` says how to run it.
