### Documentation

- **The SessionStart baseline block's token budget bounded nothing on the lane it governed, and that is how it was found ([#1526](https://github.com/robotrocketscience/aelfrice/issues/1526)).** `session_start` retrieves through `_retrieve_baseline_with_block`, which calls `retrieve()` with an **empty query**. In `retrieve_with_tiers` every relevance lane — L2.5, L1, HRR expansion, the temporal spine and the BFS hop — is gated on `query.strip()`, so only L0 contributes, and L0 is appended unconditionally and never trimmed by the budget ([#379](https://github.com/robotrocketscience/aelfrice/issues/379)). The pack loop this budget drives is never entered. Measured on a 300-lock store of 150-character beliefs: 300 hits and 61,144 rendered bytes at `token_budget=1`, at 1500 and at 100000 alike. The block is still bounded — by the lock count, which is the #379 contract — but the constant was inert, so re-tuning it would have been meaningless. It is deleted in this same release under [#1546](https://github.com/robotrocketscience/aelfrice/issues/1546); read that entry for what the deletion exposes. `tests/test_render_cost_1526.py` pins the lane's behaviour against the real call rather than a monkeypatch of it.
