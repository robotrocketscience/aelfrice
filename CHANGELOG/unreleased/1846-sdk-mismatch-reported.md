### Fixed

- **An SDK mismatch in the LLM classifier stops with an error ([#1846](https://github.com/robotrocketscience/aelfrice/issues/1846)).** `aelf onboard` and `aelf doctor --classify-orphans` treated every exception from the SDK call as a transient fault, so a `TypeError` from an SDK that no longer takes a keyword the classifier sends looked like a network error. Onboard fell back to the regex classifier with exit 0 and no message saying the model was never called. Both commands now print the exception and exit 1 without inserting or updating a belief, as they do for an auth failure. Network faults and rate limits still fall back. If you see this error, reinstall the `[onboard-llm]` extra, or pass `--llm-classify=false` to `aelf onboard` to use the regex classifier.
