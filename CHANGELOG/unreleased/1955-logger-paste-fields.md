### Added

- **Each user line in the turn log counts its pasted blocks ([#1955](https://github.com/robotrocketscience/aelfrice/issues/1955)).** The transcript logger adds `paste_blocks` and `paste_bytes` to every user line it writes to `turns.jsonl`: the number of `<pasted_content>` pastes ingest reads in the prompt, and the UTF-8 bytes of their text. A tag counts whether the host wrote it or you typed it, as in ingest. Both are integers, and no text is added. A prompt without tags gets `0` and `0`. A paste is what ingest filters as one: it runs from an opening tag to the next closing tag, or to the end of the prompt when none follows, and a paste inside a system reminder or a harness block doesn't count, because ingest cuts those first. The logger reads the prompt with ingest's own code. The host marks pastes it collapses to a placeholder; a short inline paste carries no tags and counts as typed text. If the prompt is over 2,000,000 characters or the count fails, the line is still written, without the two fields, and the logger prints one `aelf-logger:` line to stderr; a stderr that can't be written doesn't stop the line. The cuts that run before the count, which ingest shares, now take time linear in the prompt's length for any spelling of a tag name: a prompt of unclosed openers at line starts no longer takes quadratic time in the logger or in ingest. Lines written earlier have neither field, and every reader of the log ignores both.
