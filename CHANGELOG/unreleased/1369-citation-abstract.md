### Documentation

- **`CITATION.cff` no longer names removed lock mechanisms ([#1369](https://github.com/robotrocketscience/aelfrice/issues/1369), [#814](https://github.com/robotrocketscience/aelfrice/issues/814)).** The abstract said that locked beliefs carry "sharp decay-floor and demotion-pressure auto-correction". #814 removed demotion pressure in 3.2.0, and #1369 deleted the unused posterior-decay code in 5.0.0. The abstract now says only that you can lock a belief as ground truth.
