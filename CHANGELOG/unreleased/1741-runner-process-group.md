### Fixed

- **A background labeling run can't outlive its timeout through a wrapper script on macOS and Linux ([#1741](https://github.com/robotrocketscience/aelfrice/issues/1741), [#1811](https://github.com/robotrocketscience/aelfrice/issues/1811)).** Background core-gate labeling killed only the process it started, so the real `claude` behind a wrapper script could keep running and spending past the five-minute timeout. It now starts the run in a process group of its own and ends that group on a timeout, when the run exits, and when the background process gets SIGTERM, SIGHUP, SIGINT, SIGQUIT, or another signal whose default would end it, even one that arrives while the run is starting. SIGKILL, SIGSTOP, and fault signals such as SIGSEGV leave the run going.
