### Changed

- **The user-facing documentation is written in Simplified Technical English ([#1509](https://github.com/robotrocketscience/aelfrice/issues/1509)).** Twenty files — `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `docs/README.md`, and everything under `docs/user/` and `docs/concepts/` — move to ASD-STE100: one idea per sentence, active voice with the actor named, the imperative for instructions, no idiom and no metaphor, one term per concept matching the term the code uses, and each acronym spelled out at its first use. 56,175 words become 67,144; STE prose is longer, because splitting a sentence and naming a pronoun costs words. Records are deliberately out of scope, because rewriting one changes what it says happened: `CHANGELOG/`, `docs/audits/`, `docs/design/historical/`. `CODE_OF_CONDUCT.md` is out of scope too — it is adopted normative text attributed to the Contributor Covenant, and rewording it breaks both properties. No fact changes: every numeric literal, URL, link target, fenced code block, inline code span, table row and front-matter key that appears in the original still appears, verified per file by `scripts/check_doc_preservation.py`, which also fails when a reworded heading orphans a link that pointed at it. `CONTRIBUTING.md` gains a `Documentation style` section so the convention is written down rather than inferred from the diff.
