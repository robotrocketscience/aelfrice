### Fixed

- **A partial install no longer costs the SessionStart recap ([#1527](https://github.com/robotrocketscience/aelfrice/issues/1527)).** Deferring the retrieval subtree took `aelfrice.retrieval` and `aelfrice.hook_search` out of the eager `try` that sets `_IMPORTS_OK`, so an install missing either one, or missing an optional dependency such as `numpy` that only a retrieval call reaches, no longer trips the guard at the top of each lane: the fire runs and the `ImportError` surfaces mid-body, as an unhandled traceback on every fire. `user_prompt_submit`, `pre_compact` and `session_start` now answer it the way the eager guard always has, through one `_report_incomplete_install` helper the guard sites also call — one concise line, exit 0, no traceback. The arm **reports and falls through** rather than returning: `session_start` runs the belief-write recap and the wonder auto-GC after its `try`, neither of which touches retrieval, and returning early would let one absent optional dependency silently delete both.
