### Changed

- **Background core-gate labeling runs on Windows ([#1761](https://github.com/robotrocketscience/aelfrice/issues/1761)).** Since #1741 the Stop hook skipped background labeling on Windows. It now runs there when `claude` is on your `PATH`, from the native installer or from npm. The detached process starts with `DETACHED_PROCESS`, `CREATE_NO_WINDOW`, and `CREATE_NEW_PROCESS_GROUP`, and it runs `claude` with `CREATE_NO_WINDOW`. On every platform, the setting that turns hooks off in that run, `{"disableAllHooks": true}`, now reaches `claude` as a temporary `aelfrice-core-gate-*.json` file instead of a command-line argument, so cmd.exe can't reshape it on its way through an npm `claude.cmd`. The file holds nothing else, is readable only by you on macOS and Linux, and is removed when the run returns, times out, or fails to start. The reply from `claude` is now decoded as UTF-8. Before, on macOS and Linux under a locale whose encoding isn't UTF-8, a reply with bytes that encoding can't decode failed the run and left its batch open. Windows would have failed the same way through its ANSI code page. The run still removes `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN`, so it uses your `claude` login. To turn background labeling off, set `[core_gate] background = false` or `AELFRICE_CORE_GATE_BACKGROUND=0`.
