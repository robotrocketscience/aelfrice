### CI

- **The weekly mutation run tests mutants again under pytest 9.2.0 ([#1938](https://github.com/robotrocketscience/aelfrice/issues/1938)).** mutmut 3.8.0 read pytest's private `Item._nodeid` in its stats pass, and pytest 9.2.0 removed it. Once `uv.lock` moved to 9.2.0, every shard stopped with `AttributeError: 'Function' object has no attribute '_nodeid'` and `failed to collect stats`, so no mutant ran from 2026-11-08 on, and the per-PR job listed every mutant as `not checked`. mutmut 3.8.1 reads the public `nodeid`, and `mutation.yml` now pins it in all four places. Scoped to `src/aelfrice/inedible.py` and its tests under pytest 9.2.0, mutmut 3.8.0 left all 18 mutants `not checked`, and 3.8.1 killed 17 and reported 1 survivor. The shard plan's contract tests pass on 3.8.1 unchanged. `tests/test_mutation_harness_1938.py` runs `mutmut run` over a one-function project with the installed pytest and requires its mutant to be killed. The plan job's contract step runs it against the pinned mutmut, so an incompatible mutmut and pytest pair now fails the plan job in seconds, before any shard starts. A second test fails when the four mutmut pins in the workflow name different versions.

  Two tests then stopped every shard before its first mutant. mutmut runs its stats pass and its clean run as two pytest sessions in one process. `test_the_http_client_is_closed_when_the_build_fails` took its fake SDKs as parametrize instances, so the second session counted 2 closes. It now builds each fake per test. `test_the_reply_decodes_as_utf8_under_a_non_utf8_locale` opens a batch under the classifier version of `mutants/src` and labels it in a subprocess under the original source's version, so in the shard that mutates `core_gate.py` the subprocess reports `stale_version`. It joins the other subprocess tests in `pytest_add_cli_args` as a `--deselect`. Under mutmut 3.8.1 on Python 3.14, scoped to `llm_classifier.py` and the SDK tests, the clean run now passes and 229 mutants are killed. Scoped to `core_gate.py` and the locale tests, 41 are killed.
