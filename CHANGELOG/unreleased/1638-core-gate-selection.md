### Changed

- **Core selection applies the core admission gate ([#1638](https://github.com/robotrocketscience/aelfrice/issues/1638)).** `aelf core`, the SessionStart `<core>` lane, and the core membership that `aelf doctor --gc-filesystem-corroboration` reports now read each candidate's cached label under the current classifier version, in one batched lookup per selection rather than one per belief. The gate applies only to the corroboration and posterior arms; locked beliefs aren't gated. A belief with label A is admitted. A belief with label B is admitted only if fewer than two of its corroborations count under the [#1635](https://github.com/robotrocketscience/aelfrice/issues/1635) episode rule: its corroboration count when its sightings span two or more episodes, and zero otherwise. A belief with label C is never admitted. A belief with no label under the current version follows the earlier rule, so nothing leaves core before it's classified. Core changes only as labels are accepted.

  `aelf core` text output doesn't show labels. With `--json`, the row for a labeled belief gains a `core_gate_label` field, and a row without a label has no such field. A store written before the label table existed and opened read-only reads as having no labels.

  The `--gc-filesystem-corroboration` report now also lists the beliefs that would enter core once the rows are deleted, on a line that appears only when there are any. Deleting rows can admit a belief: a B-labeled belief can fall below two corroborations, and removing one sighting can join two short gaps into one gap long enough to start a second episode.
