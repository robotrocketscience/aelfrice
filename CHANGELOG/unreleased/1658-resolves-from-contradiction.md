### Changed

- **`aelf resolve` now writes a `RESOLVES` edge beside each `SUPERSEDES` edge, so the `RESOLVES` readers finally have a writer ([#1658](https://github.com/robotrocketscience/aelfrice/issues/1658)).**
  - **Before:** nothing wrote a `RESOLVES` edge. `aelf introspect` never reported `decided` or `decides`, and the wonder GC exemption for phantoms with a `RESOLVES` edge never applied.
  - **Now:** when `resolve_contradiction` settles a `CONTRADICTS` pair, it writes `RESOLVES` from the winner to the loser, the same direction as `SUPERSEDES`. `aelf introspect` shows the winner as `decides` and the loser as `decided`, and a phantom on either side of a resolved pair is exempt from `aelf wonder --gc`. A second resolution of the same pair writes no second edge. Both edges and the audit row commit in one transaction, so a failure part-way leaves none of them, and `aelf resolve` retries the pair on its next run. `ResolutionResult` gains a `resolves_created` field.
  - **Ranking:** free-text retrieval is unchanged. The edge has valence 0.0, the BFS walk has no weight for it, and its stored weight is 0.0, below the clustering floor of 0.4. A test compares `retrieve()` output with and without the edges. The HRR structural index binds every edge type, so the edge answers a `RESOLVES:<id>` marker query and adds crosstalk to the winner's row for other `<KIND>:<id>` marker queries. Any one-line prompt that starts with an edge type, a colon and a non-space character, such as `SUPERSEDES:the old plan`, routes to that lane.
  - **`aelf wonder`:** the default seed is the non-locked belief with the most outgoing edges, so a contradiction winner's extra edge can make it the seed. The random-walk strategy picks uniformly over outgoing edges, so it can follow the new edge. Its only shipped caller, the offline bake-off, builds a corpus with no `CONTRADICTS` edges and is unaffected. On 20 synthetic stores of 300 beliefs and 900 random edges, the default seed changed in 7 stores, each time to a contradiction winner, and the random-walk phantom set changed in all 20. To reproduce, run `uv run python benchmarks/resolves_edge_effect_1658.py`.
  - **Limits:** pairs that an earlier `aelf resolve` already settled keep their `SUPERSEDES` edge and get no `RESOLVES` edge, because `aelf resolve` skips settled pairs. For the same reason, a pair that already has a `SUPERSEDES` edge from another writer, such as the commit hook, gets no `RESOLVES` edge. The detector-thresholds manifest moves to version 3 to pin `RESOLVES_WEIGHT`.
