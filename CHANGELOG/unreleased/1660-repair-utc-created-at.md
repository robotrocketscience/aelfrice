### Added

- **`aelf doctor --repair-utc-created-at` rewrites the offset-form dates that onboard stored before #1611, and re-chains the temporal spine ([#1660](https://github.com/robotrocketscience/aelfrice/issues/1660)).** Before [#1611](https://github.com/robotrocketscience/aelfrice/issues/1611), onboard stored each commit date with its author's local offset, such as `2026-01-01T10:00:00-08:00`. Next to `Z` timestamps, text order then differs from real order, and the temporal spine links some beliefs backwards in time. The command reports the affected beliefs, the sessions they're in, and the spine edges a re-chain would remove and write. It changes nothing unless you add `--apply`. With `--apply`, it rewrites each value as UTC, such as `2026-01-01T18:00:00Z`, and rebuilds the spine of those sessions only. It also rewrites the matching ingest-log timestamps, so rebuilding beliefs from the log doesn't bring the offsets back. A session whose spine you cleared stays cleared, and prose-derived `TEMPORAL_NEXT` edges are kept. Values already in UTC (`Z` or `+00:00`) and values that don't parse are left as they are, so a store with no offset dates is left untouched. The command holds the store's write lock while it runs, about 0.3 seconds for 12,000 rows.
