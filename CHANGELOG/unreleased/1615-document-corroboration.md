### Fixed

- **Re-onboarding no longer counts as re-asserting your documents ([#1615](https://github.com/robotrocketscience/aelfrice/issues/1615)).** Every `aelf onboard` or repository scan ran as a new session, and nothing recorded which file a row came from, so re-reading unchanged text added a corroboration row on every run. On this repository, three scans gave all 12,633 doc beliefs a corroboration count of 2. Untracked files and directories outside git then reached `aelf core` after three runs. A paragraph at a second path was also reported as new, and classified again, on every run. Now filesystem and commit ingest insert new content but never corroborate an existing belief: a rescan, a moved file, a copied paragraph, or a rebased commit message adds nothing. The onboard pre-scan counts a paragraph as present when its text is already stored. Corroboration from transcripts, `aelf lock` and `aelf remember`, wonder, and the memory mirror is unchanged. Rows already in a store aren't removed.
