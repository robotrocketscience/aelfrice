### Fixed

- **Two transcript-logger registrations no longer write one turn twice ([#1956](https://github.com/robotrocketscience/aelfrice/issues/1956)).** The host runs matching hooks in parallel, so when your user and project settings files each hold a logger entry, both copies fire at once. The duplicate guard read the log's last line and then appended without a lock, so each copy missed the other's line and both landed. The logger now holds an advisory lock on a `turns.jsonl.lock` file beside the log while it reads and appends. If another process holds the lock for more than 0.25 seconds, or the file system can't lock, the logger appends through the unlocked guard, so the hook never stalls or drops a turn. `aelf doctor` now reports a logger event that your user and project settings files wire with different commands, which the per-file duplicate check missed. The same command in both files runs once, so doctor doesn't report it.
