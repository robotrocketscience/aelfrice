### Changed

- **A belief already injected verbatim this session is re-injected as a one-line reference ([#1382](https://github.com/robotrocketscience/aelfrice/issues/1382)).** `UserPromptSubmit` repeated the identical `<belief>` element on every turn that retrieved it. It now writes `seen <id>: "<topic>"` into the locks manifest instead, because the full text is already above in the same context window. Default-on; export `AELFRICE_TURN_DIFFERENTIAL=0` for the previous behaviour. Each `SessionStart` opens a new epoch and resets the record — that fire is the only event which unconditionally re-emits every locked belief verbatim, and the only one after which earlier text can no longer be assumed present, so `begin_epoch` replaces rather than unions. A change of session id is treated the same way. The failure direction is one-way and asserted by test: a missing, unreadable, malformed or foreign ledger yields the empty set and everything renders verbatim, so the mechanism can cost a repeated injection but can never suppress a belief the model has not been shown. Nothing is recorded for a fire whose block the `[memory_block]` off-switch ([#1359](https://github.com/robotrocketscience/aelfrice/issues/1359)) suppressed — that block never reached the window, and recording it is the one path by which this feature could under-inject. The saving is bounded by the 80-character topic cap rather than by the tag overhead: a 40-character belief saves 24 characters, while a 746-character belief collapses to a ~100-character line. `src/aelfrice/injection_ledger.py` and its render rule shipped unwired in an earlier branch — imported by no production module, with zero callers of `begin_epoch` and `record_rendered`, and every production call site passing an empty set — so `tests/test_turn_differential_wiring_1382.py` fires the real hook entry points and mutation-proves each of the four production edges turns a named test red.
