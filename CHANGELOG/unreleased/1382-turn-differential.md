### Added

- **An opt-in turn-differential for the injected memory block ([#1382](https://github.com/robotrocketscience/aelfrice/issues/1382)).** With `AELFRICE_TURN_DIFFERENTIAL=1`, a belief already injected verbatim in this session is re-injected as a one-line `seen <id>: "<topic>"` entry in the locks manifest instead of the identical `<belief>` element, because the full text is already above in the same context window. **Default-off**, ratified 2026-08-19, reversing the 2026-08-11 default-on ruling — that ruling rested on the failure direction being one-way, and adversarial review of the implementing PR showed it was not. `begin_epoch` sat inside a `if body:` guard, so a store with no locked beliefs rendered an empty SessionStart baseline, never opened an epoch, and left the pre-compaction ledger live under the same `session_id`; every later turn then emitted `seen <id>` for text the window no longer held, reducing that belief to an 80-character stub for the rest of the session. Fixed three ways: the epoch reset is unconditional, `PreCompact` resets too (it is the event actually guaranteed to precede compaction, and it fires whatever the rebuilder's `trigger_mode` is), and a boundary carrying no `session_id` now deletes the ledger rather than returning early and leaving it live. The second reason for default-off is that the saving can be negative: a `seen` entry opens the `<aelfrice-locks-manifest>` wrapper on a block that had none, a fixed ~237 characters, so a single-belief block must exceed ~310 characters of content before the change saves anything — against a recorded median content length of 86. Small blocks of short beliefs get bigger; large or long blocks get much smaller. No aggregate percentage is published, because nothing in the tree re-derives one. Writes are gated on `emit_memory_block` ([#1359](https://github.com/robotrocketscience/aelfrice/issues/1359)): a suppressed fire put nothing in the window, so recording it would reference content the model never saw.
