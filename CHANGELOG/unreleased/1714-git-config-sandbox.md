### Fixed

- **An exported git config or template no longer reaches the test suite ([#1714](https://github.com/robotrocketscience/aelfrice/issues/1714)).** The suite's sandbox `HOME` hides `~/.gitconfig`, but `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` name config files directly, `GIT_CONFIG_COUNT` and `GIT_CONFIG_PARAMETERS` carry settings in the environment, and `GIT_TEMPLATE_DIR` names the hooks that `git init` copies. On 33 git-using test files, with each exported at a config or template that installs an external hook, `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` each failed 20 tests, errored 6, and ran the external hooks 596 times; `GIT_TEMPLATE_DIR` failed 6 and ran them 559 times. The suite-wide sandbox fixture in `tests/conftest.py` now points the global config at `.gitconfig` in the sandbox home, sets `GIT_CONFIG_NOSYSTEM`, and clears the other four variables. The same runs now pass with no external hook runs. `tests/test_git_config_sandbox_1714.py` runs a second pytest with all five exported and fails if git reads any setting from outside the sandbox home or copies a hook from the template.
