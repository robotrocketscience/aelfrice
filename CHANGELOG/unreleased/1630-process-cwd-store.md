### Internal

- **Tests now pin which directory a prompt's store comes from ([#1630](https://github.com/robotrocketscience/aelfrice/issues/1630)).** The UserPromptSubmit hook reads the store from its own working directory, and the payload's `cwd` field doesn't change that. The same holds for the shared store handle, the typed `/aelf:` command, the command-outcome row, and the session-state files. Until now, no test held that choice, so a change could split one prompt across two stores without failing anything. New tests give the hook a payload `cwd` that names a different repository. They check that every consumer still uses the hook's own directory, that a typed `/aelf:scope-out` still takes effect on the next prompt, and that an explicit `AELFRICE_DB` still overrides both directories. No behavior changed. The host runs hooks in the session's current directory, and the [measurement on #1630](https://github.com/robotrocketscience/aelfrice/issues/1630#issuecomment-5974623437) found the two directories never diverged in practice.
