### Removed

- **Three v2.0 bench gates graded code that does not exist, and they are retired rather than left in the denominator ([#1579](https://github.com/robotrocketscience/aelfrice/issues/1579)).** The bench-gate tier scaffolded 20 modules reporting "no verdict", which reads as *unfunded labelling*. For `dedup`, `enforcement`, and `promotion_trigger` it was not: there is no function to grade, so no corpus of any size could produce a verdict, and the count overstated how much of the tier a labelling push could recover. The denominator is now 17 and every module in it names work a corpus would actually unblock. **`enforcement` was dropped, not deferred.** `docs/design/v2_enforcement.md` records the disposition in its status line — "H2 dropped per § H2 below" — and § H2 states the wording is deliberate: "Final decision: drop, not defer. Removing the temptation to revisit 'just port the safe predicates' prevents incremental erosion of the security stance." The dropped predicate set included `command_succeeds:cmd`, which would have executed arbitrary shell from belief content with no allowlist and no sandbox. The gate was scaffolding for a capability the project decided on security grounds not to ship, so keeping it implied a reopening that is not coming. **`promotion_trigger` shipped store-shaped under [#229](https://github.com/robotrocketscience/aelfrice/issues/229), and is already covered on every public CI pass.** The capability landed as `find_promotable_phantoms(min_corroborations=..., min_sessions=...)` plus a Jaccard lock match, not as a module taking a belief sequence. The corpus schema for this module is a `list[str]` of ids, which cannot express a corroboration count or a session count, so even a perfectly labelled corpus would grade a function the product does not have. `tests/test_promotion_adversarial.py` covers the shipped rule on every public CI run, rather than once per release cut. **`dedup` was the live landmine.** Its guard caught `ModuleNotFoundError`, but `aelfrice.dedup` imports — the module is real, and ships `jaccard`, `levenshtein_ratio`, `cluster_pairs`, `find_near_duplicate_locks`, and `dedup_audit`. What it has never had is `classify`, which the gate called on the next line, so the first row mounted under `<corpus>/dedup/` would have turned a clean skip into an `AttributeError` at a release cut. There is a second mismatch underneath: the corpus label set is ternary (`duplicate` / `near-duplicate` / `distinct`) while the shipped predicate is one binary threshold, and nobody has defined the `near-duplicate` band — so anyone labelling rows today would be labelling to a boundary that does not exist. If `dedup` is ever revived, define the band and write `classify` first, then re-mount rows; do not author new ones.

  The reason this cost anything is that nothing failed at authoring time. The whole tier skips without `AELFRICE_CORPUS_ROOT`, so a gate against a module that was never written is indistinguishable from a gate waiting on rows, and the bill arrives at the release cut — the one place [#1477](https://github.com/robotrocketscience/aelfrice/issues/1477) made the tier mandatory, and where [#1502](https://github.com/robotrocketscience/aelfrice/issues/1502) already showed that a check nobody can turn green teaches readers to skip the reds beside it. `tests/test_bench_gate_graded_code_exists_1579.py` closes that: it walks every file under `tests/bench_gate/`, asserts each `aelfrice.*` module it imports has a file under `src/aelfrice/`, and asserts each attribute read off one of those modules exists on it. The second assertion is the one `dedup` needed — an importable module is not a gradable one, and a module-existence check alone passes the exact case that broke. It runs unmarked and corpus-free, so the next scaffold-before-code gate reds on its own pull request. Mutation-checked three ways: a planted gate importing `aelfrice.nonexistent_module` reds the module check, one importing a missing name off the package reds the member check, and one reproducing the `dedup` shape — a real module, an absent attribute — reds the attribute check.
