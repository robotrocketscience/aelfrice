### Internal

- **Tests now cover a file missing from a non-empty recency map ([#1682](https://github.com/robotrocketscience/aelfrice/issues/1682)).** Earlier fixtures gave every file an entry or used an empty map, so a lookup that fell back to another file's date when a file had no entry passed them. New fixtures for `extract_ast` and `extract_filesystem` leave `p/m` out of the map, date its sibling `p/n` and a file in another directory, and assert that `p/m` has no commit date. An onboard handshake with one committed and one untracked directory asserts that the untracked files' beliefs take the `now` passed to `accept_classifications` as `created_at`, not the committed date. A fallback to any other entry now fails two tests at each lookup site, and a fallback limited to the same directory fails one. No production code changed.
