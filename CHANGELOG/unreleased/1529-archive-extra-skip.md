### Fixed

- **Six uninstall tests skip, rather than fail, when the optional `[archive]` extra is absent ([#1529](https://github.com/robotrocketscience/aelfrice/issues/1529)).** `archive` is an optional extra (`cryptography>=50.0`) and is not in the `dev` dependency group, but three test modules exercised `aelf uninstall --archive` with no guard, so a developer install without the extra failed six tests with `RuntimeError: --archive requires the 'archive' extra`. Measured on a clean sync of `main`, the whole suite went `6 failed, 8547 passed` without the extra and `8553 passed` with it. Because `aelf-pr-open.sh` gates on a local `pytest` run, that blocked opening any pull request, on any subject, until the contributor traced six unrelated uninstall failures back to one missing optional dependency. The guard is `pytest.importorskip("cryptography", reason=...)`, the convention this suite already used at `tests/test_lifecycle.py:259` and `:280` and in five other modules for the `[benchmarks]` extras; the three sibling modules had simply been written without it. A skip can delete coverage as quietly as a failure blocks work, so CI now asserts `import cryptography` immediately after the sync step: that import is the guards' only condition, so proving it holds proves none of the six can skip on a runner. Verified in both directions — without the extra the six report as skips with the reason and nothing fails, and with the extra all 85 tests in those modules run with zero skips.
