### Added

- **K3: the budget census's noise floor now carries an A/A term, and it is 0.0pp ([#1546](https://github.com/robotrocketscience/aelfrice/issues/1546)).** `docs/design/budget_discriminability_k0_preregistration.md` builds the floor as `NF = max(1.96 * sqrt(0.25 / N), 9.5pp, A/A_band)` and records that the third term was missing, so the band covered grader disagreement and binomial sampling noise and no instrument noise at all. `scripts/budget_discriminability_aa_replicate.py` supplies it. The census is deterministic — `--check` hashes two reports on every run — so a replicate that re-ran the same inputs would measure zero by construction; the pre-registered perturbation is instead belief **insertion order**, re-ingested under a seeded permutation that holds the corpus, the gold sets, the grid, the lane set, and every belief's content fixed and moves only the rowid SQLite assigns. The producer reuses `budget_discriminability_census.report(queries=...)` rather than reimplementing EC, so the lanes, grid, cost functions, exclusion rules, block-identity check, and containment check are the census's own; `report()` gained an optional `queries` argument for it, and the census's `--check` hash is unchanged at `4534221b9893`. Measured over 9 replicates at base seed 1546: `aa_band_pp` 0.0, on all six lanes and all 18 lane-by-corpus cells, with N holding at 7 and 0 bound violations. `NF` is unchanged, because `max(37.0398, 9.5, 0.0)` is still 37.0398pp.

  The zero is earned rather than asserted. `tests/test_budget_aa_replicate.py` drives the replicate against a fake `retrieval.retrieve` that reads the store's `rowid` column — the one thing the perturbation moves — and requires the band to go non-zero on **every** lane; it reports 66.6667pp overall and 57.1429pp per lane against that fake, and 0.0pp again once the shipped path is restored. Two source mutations red the control: making `permuted_corpora` return the committed order, and making `spread` return 0.0. A second guard one level down sweeps all 2070 lane-by-query-by-grid arms and finds 0 whose retrieved list moves at all, which separates a real zero from one produced by movements that cancelled; that counter is mutation-checked the same way. The mechanism is visible in `src/aelfrice/store.py`: the FTS search orders by `bm25(beliefs_fts), b.id`, a content-derived tie-break rather than the rowid, and the one lane that does order by rowid — the temporal spine — never runs on the census's edgeless `:memory:` stores. Read the band as scoped to that configuration: `docs/design/budget_discriminability_aa_result.md` records what the run does not determine, including whether insertion order matters on an edge-bearing store.
