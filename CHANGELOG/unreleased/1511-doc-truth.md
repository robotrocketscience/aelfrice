### Fixed

- **Seven user-facing documentation statements that disagreed with the code ([#1511](https://github.com/robotrocketscience/aelfrice/issues/1511)).** The ASD-STE100 conversion ([#1509](https://github.com/robotrocketscience/aelfrice/issues/1509)) read all twenty user-facing documents against the source and surfaced these; that change was scoped "change no facts", so none were corrected there. `SECURITY.md` named one default outbound call where `README.md` and `PRIVACY.md` both name two — the update notifier and the pre-issue duplicate guard, default-on since v3.4.0 — and `SECURITY.md` is the document a reader consults for exactly that fact. `docs/user/INSTALL.md` told the reader to run `aelf doctor --prune` while its own code block two lines below used `--fix`; the parser defines `--fix`, `--prune-dormant` and `--prune-noise`, and no bare `--prune`, so the prose produced an argparse error. `INSTALL.md` and `LIMITATIONS.md` promised that the full suite runs on macOS and Linux on every pull request, but no workflow has ever used a macOS runner — the claim is replaced by what the workflows provide, a Linux full suite plus a Windows smoke job. `docs/concepts/ARCHITECTURE.md` said 31 modules against 117 `.py` files where the table has 32 rows and the tree holds 127. `docs/concepts/PHILOSOPHY.md` said exploration would ship "in a future version"; `src/aelfrice/exploration.py` ships today behind the default-off `[retrieval] exploration_enabled` flag, and the determinism argument in that paragraph is why the default is off, so the argument is kept and the stale half replaced. `docs/user/LIMITATIONS.md` described the removed Model Context Protocol surface in the present tense. Nine cross-file anchor links pointed at headings that no longer exist — not the fourteen reported, because GitHub does not collapse runs of whitespace when it builds a slug, and a collapsing slugger invents five phantoms. Every corrected figure is now derived rather than typed: `tests/test_docs_truth_1511.py` reads the workflow directory, the module table and the tree, and `tests/test_docs_cross_file_anchors_1511.py` resolves every cross-file anchor offline with a non-vacuity assert, covering the class the network `link-check` workflow cannot.
