### Internal

- **`expand_seeds` takes the edge kinds it probes ([#1795](https://github.com/robotrocketscience/aelfrice/issues/1795)).** `aelfrice.hrr_expand.expand_seeds` accepts a `kinds` keyword, a tuple of edge kind names, and the module gains the global `probe_kinds_override` of the same type. When `kinds` is `None`, the default, the function reads `probe_kinds_override`. When that is also `None`, its default, the function probes `hrr_expand_edge_types()` as before. The retrieval lane passes neither, so a store that no benchmark has touched ranks as it did. The real-store A/B harness under `benchmarks/` sets the override to probe other kinds through the production `retrieve()` path, which has no parameter for them. Shipped in [#1801](https://github.com/robotrocketscience/aelfrice/pull/1801) as commit [`1e138ba9`](https://github.com/robotrocketscience/aelfrice/commit/1e138ba9c1d2640a74a8efb38fa1d78fdd9b2c75), which carried no changelog entry.
