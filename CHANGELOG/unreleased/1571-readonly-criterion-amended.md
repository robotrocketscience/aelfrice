### Documentation

- **The read-only routing criterion says what it can truthfully assert ([#1571](https://github.com/robotrocketscience/aelfrice/issues/1571)).** [#1416](https://github.com/robotrocketscience/aelfrice/issues/1416)'s expanded matrix asked that a routed read command perform no preliminary writable open *and* emit no failed-write warning. Neither half survives the writable-first order, and nothing in the code was wrong. The first is refuted unconditionally: `open_store_for_read()` always attempts the writable open before it can know whether the fallback is needed, so no routed command satisfies it on any store. The second is refuted on one shape — a store whose directory is frozen, whose write-ahead log sidecars are live, **and whose schema needs no write to open**. There the writable attempt succeeds, the `mode=ro` handle is never taken, `aelf search` goes on to attempt its `.bm25f` sidecar write, and that write fails with a non-fatal warning. The schema qualifier is load-bearing: an outdated schema makes the open-time DDL fire and fail, which does reach the fallback, and `tests/test_readonly_store_1416.py` constructs exactly that state by dropping `exploration_events` while holding the sidecars live. Both halves are therefore unsatisfiable while the writable-first order stands — and that order stands by the 2026-08-09 ruling, because preferring `mode=ro` unconditionally imposes degraded semantics (no migration, no expired-lock sweep) on every user whose store is perfectly writable. The criterion is therefore narrowed to what holds — the `mode=ro` fallback handle emits no failed-write warning, with the preliminary writable attempt retained and expected — and the reasoning lands at `open_store_for_read()` rather than in a closed issue, so the next reader meets it at the code. Making the sidecar write conditional on directory writability was considered and declined: it silences an accurate message — a write genuinely was attempted and genuinely failed — at the cost of a writability probe on a hot path that nobody has measured. Whether a frozen directory with live sidecars occurs in the field is unrecorded, and does not matter here, because the chosen disposition changes no design.
