### Fixed

- **`aelf migrate --apply` copies every column of each belief ([#1911](https://github.com/robotrocketscience/aelfrice/issues/1911)).** The copy built each target belief from 13 fields, so `valid_to`, `lock_tier`, `lock_expires_at`, `session_id`, `retention_class`, and `last_confirmed_at` took their defaults in the target store. A retired belief came back active, a `reference` lock became `frozen`, and a time-boxed lock became permanent. The command also left the `belief_corroborations` rows behind, which reset each copied belief's corroboration count to 0, and it dropped the anchor text of each copied edge. The copy now carries every column the source store has, copies the corroboration rows of each belief it inserts, and keeps edge anchor text. A retired belief stays retired and stays out of keyword search. A source store from an older version that lacks some of these columns still migrates, and the missing columns take their defaults as before.
