### Removed

- **The store drops the unused `hibernation_score` and `activation_condition` columns from `beliefs` ([#1658](https://github.com/robotrocketscience/aelfrice/issues/1658)).** The two columns were the storage half of a hibernation lifecycle (v2.0, #196) that was never built: no code path wrote a non-NULL value, and measurement later found that a cold-decay sink does not help this workload. The first open after you upgrade runs two `ALTER TABLE beliefs DROP COLUMN` migrations, the same shape as the `demotion_pressure` drop in #814. Each drop rewrites the `beliefs` table, which took about 0.1 s per column on a copy of a 101 MB store. The `Belief` dataclass loses both fields, `aelf doctor replay` stops comparing them, and the design memo moves to `docs/design/historical/hibernation_lifecycle.md`. An older aelfrice that opens the store afterwards re-adds both columns as NULL through its own migrations, so a downgrade still works.
