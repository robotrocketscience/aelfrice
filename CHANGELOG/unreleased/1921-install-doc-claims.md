### Documentation

- **INSTALL.md describes the statusline, merge commits, the doctor hook check, and uninstall as the code behaves ([#1921](https://github.com/robotrocketscience/aelfrice/issues/1921)).** The statusline also shows `aelf L0=N L1=N`, plus `?=N` for beliefs that a potentially-stale edge points at, whenever it can read a store that holds beliefs, and `AELF_STATUSLINE_COUNTS=0` hides it. The counts include retired beliefs, an expired time-boxed lock stays in `L0` until aelfrice next opens the store for writing, and a store the statusline can't read shows no counts and no error. Git runs no `post-commit` for a merge that completes by itself, but a merge you finish with `git commit`, after resolving conflicts or after `git merge --no-commit`, runs it, and commit-ingest reads that message. `aelf doctor` reports every default-on manifest hook missing from `settings.json` unless you opted out of it. `aelf uninstall` has no default disposition: without `--keep-db`, `--purge`, or `--archive PATH`, it prints an error and exits 2.
