### Performance

- **Positive sentiment no longer reads the whole hook audit log on every fire ([#1674](https://github.com/robotrocketscience/aelfrice/issues/1674)).** To find the beliefs your previous prompt was shown, the sentiment lane read all of `hook_audit.jsonl` and its rotated `.1` file, which can reach about 20 MB. It now reads backward from the end and stops at the session's most recent prompt row. On a 20 MB log, the lookup went from 96.7 ms to 0.14 ms (median of 15). On this project's live 1.7 MB log, it went from 8.2 ms to 0.08 ms, with the same answer. A session with no prompt row still reads every line, and that got faster too: 99 ms to 71 ms at 20 MB. One difference from the whole-file read: a corrupt line older than the match is no longer reached, so it doesn't turn the answer empty.
