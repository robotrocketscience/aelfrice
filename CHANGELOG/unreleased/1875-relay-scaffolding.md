### Fixed

- **Relay text that opens a user record is no longer stored as your words ([#1875](https://github.com/robotrocketscience/aelfrice/pull/1875)).** The host writes a teammate's brief, a background agent's report, another session's message, and its own cross-session notices as user records. When one of these opens the record, the transcript logger and ingest now cut it and keep what follows, including a relay block later in the record. No cut is made when it would change how ingest reads the rest of the record. A relay tag at the start that never closes takes the record up to the first paste, words you typed there included, and pastes stay as they were. WebSearch and WebFetch queries to memory now drop function words and repeated terms before the five-term cut, and Grep and Glob patterns drop only repeats.
