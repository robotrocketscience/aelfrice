### Fixed

- **Scheduled continuation prompts no longer become user beliefs ([#1780](https://github.com/robotrocketscience/aelfrice/issues/1780)).** The host replays a scheduled prompt as a user turn, and the transcript logger wrote it to `turns.jsonl` like a typed prompt, so ingest stored the model's own text as yours. The `UserPromptSubmit` payload carries no marker for these prompts. The logger now reads a bounded tail of the host transcript at `transcript_path`, and skips the prompt when its newest matching user record carries `isMeta` or `turnOrigin: "scheduled"`. A missing or unreadable transcript, no matching record, or any error in the check logs the prompt as before. On a 50 MB synthetic transcript the check took 2.0 ms median and 3.2 ms at the 99th percentile in the slowest case measured.
  - **Cleaning up existing beliefs:** `aelf doctor --retire-scheduled-prompts PATH...` reads host session files, or the `*.jsonl` files under a directory, and lists the beliefs that only scheduled or meta prompts produced. Add `--apply` to retire them; `aelf restore <id>` brings one back. A belief that a typed prompt also produced is kept. So is a locked belief, a belief you promoted or confirmed, and a belief that another source, such as the host memory mirror, corroborated. Run it as its own doctor pass.
