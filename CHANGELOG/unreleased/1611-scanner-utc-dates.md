### Fixed

- **Git author dates are stored in UTC ([#1611](https://github.com/robotrocketscience/aelfrice/issues/1611)).** `aelf onboard` and the onboard handshake used a file's or commit's git author date as `created_at`, and git keeps the author's local offset (`2026-01-01T10:00:00-08:00`). `created_at` is ordered as text, so once a store mixed those rows with the `Z` rows every other writer produces, some beliefs sorted out of real order and the temporal spine linked them backwards in time. The scanner now rewrites each git date as `YYYY-MM-DDTHH:MM:SSZ` when it reads it. If every row you onboarded carries the same offset and nothing else wrote to the store, you saw no symptom, which is how this went unnoticed. This change covers new writes only; rows already in a store keep their offsets until [#1660](https://github.com/robotrocketscience/aelfrice/issues/1660) rewrites them.
