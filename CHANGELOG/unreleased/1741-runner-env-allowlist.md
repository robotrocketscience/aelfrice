### Changed

- **Background core-gate labeling passes the CLI an allowlist of your environment ([#1741](https://github.com/robotrocketscience/aelfrice/issues/1741), [#1811](https://github.com/robotrocketscience/aelfrice/issues/1811)).** It used to remove a few named variables. It now passes only what a CLI needs to start: `PATH`, your home folder, user, and shell, the locale and time zone, the temporary folder, the terminal, and `CLAUDE_CONFIG_DIR`. So no token, cloud credential, provider switch, endpoint, proxy, or model override you exported reaches a run, whatever it is called. Locale variables pass by name, so `LC_SECRET_TOKEN` doesn't. `NODE_EXTRA_CA_CERTS` and `SSL_CERT_FILE` are dropped too, so if your network needs a custom certificate authority, background runs can't reach the model. If your only login is an API key or another environment variable, or you reach the model through a proxy or a cloud provider set in your environment, background labeling fails closed: each run fails with nothing spent, and its batch stays open until you run `aelf doctor core-gate --emit`. Set `[core_gate] background = false` to stop the runs.
