### Fixed

- **A stored prompt keeps its inline code and URLs ([#1874](https://github.com/robotrocketscience/aelfrice/issues/1874)).** Sentence extraction removed both, which left a hole in the sentence, so a search for the command or the link found nothing. Now `` Run `zqtool --check` first. `` stores whole, with its backticks, and `/aelf:search zqtool` finds it. Fenced code blocks stay removed, as does text between backticks paired across lines. A line that holds only inline code or URLs stays dropped. A `.` inside a code span no longer ends a sentence, and a `.` after a URL does. New sentences can produce `file_path` and `url` entities, and a URL entity no longer takes a closing backtick or a trailing stop, or loses to a path inside it. A URL now reaches the store with its query string, so a token in a pasted link is stored too. Existing beliefs don't change. The next ingest of a prompt with a span adds a whole belief next to the holed one, because a belief's id reads its exact text.
