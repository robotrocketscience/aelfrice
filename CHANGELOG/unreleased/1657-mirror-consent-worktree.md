### Fixed

- **The claude-memory mirror now gets consent from a linked worktree, and `aelf doctor` warns when it never did ([#1657](https://github.com/robotrocketscience/aelfrice/issues/1657)).** Consent is recorded at `aelf setup` only when the project's memory directory exists. `derive_memory_dir` encoded the working directory itself, but the host keeps a worktree session's memory under the main checkout. So `aelf setup` or `aelf reconcile-claude-memory` from a worktree deferred consent forever, and the installed hook never wrote a row.
  - **Worktree mapping:** `derive_memory_dir` now maps a linked worktree to its main checkout by reading the `.git` file and the worktree's `commondir`, without running `git`. A plain checkout, a repository nested inside a worktree, a submodule, and a worktree of a bare repository are unchanged. Memory filed under a worktree's own path is no longer looked up there; the host doesn't write any (none of 17 worktree project directories on one machine had a `memory/` folder).
  - **Doctor warning:** `aelf doctor` now warns when the mirror hook is installed and the project has memory, but no env value, TOML key, or consent sentinel has turned the mirror on. The warning gives the fix. An explicit opt-out doesn't trigger it, and the warning doesn't change the exit code.
  - **Docs:** `docs/user/INSTALL.md` now says when consent is and isn't recorded.
