### Internal

- **`supports_log` exposes the candidate pairs the reworded-support pass matches ([#1650](https://github.com/robotrocketscience/aelfrice/issues/1650)).** `aelfrice.supports_log.iter_reworded_candidates(store, supporters)` applies the pass's eligibility rules to each `(belief_id, ingest_log_id)` pair and yields a `SupportCandidate` for every candidate target, matched or not. The frozen dataclass carries the supporter's id, text, ingest log id, and session id, the target's id and text, and `match`, which holds the matcher's `RewordedMatch` or `None` when the matcher rejects the pair. The generator only reads, so it runs on a store opened read-only. `log_reworded_support` now records the matched candidates through this generator and writes the same `belief_support_evidence` rows as before. The sweep for the #1650 precision gate under `benchmarks/` replays the same rules on a copy of a store with it. Shipped in [#1794](https://github.com/robotrocketscience/aelfrice/pull/1794) as commit [`a7c0d50a`](https://github.com/robotrocketscience/aelfrice/commit/a7c0d50a99a06b6ad33d3476dd6aecdbbcd3a1c7), which carried no changelog entry.
