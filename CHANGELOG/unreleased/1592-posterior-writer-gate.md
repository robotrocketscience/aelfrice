### Added

- **`scripts/check_posterior_writers.py` gates the set of code paths that can write a belief's posterior ([#1592](https://github.com/robotrocketscience/aelfrice/issues/1592)).** #1592 AC2 asks which paths write `beliefs.alpha` / `beliefs.beta`, and [#1359](https://github.com/robotrocketscience/aelfrice/issues/1359) established that writing the answer down is not enough — that enumeration surfaced a new unguarded writer every review round, because nothing stopped one being added between rounds. The checker enumerates writers from the AST, runs as a CI job, and fails when the set changes without its manifest changing with it. It finds 21, of which **12 can move a posterior mean and only two are meant to**: `apply_feedback` on evidence, and `clamp_ghosts` deliberately lowering an alpha. Eight of the remaining ten are callers of `update_belief`, a whole-row write of an in-memory snapshot, so promotion, unlock, devalidate, scope change, review, orphan reclassification, autolock, and the lock command each load a belief, change one unrelated field, and write `alpha`/`beta` back along with it — the shape [#1168](https://github.com/robotrocketscience/aelfrice/issues/1168) found losing 180 of 240 concurrent feedback events. Detection is AST-based rather than textual because `clamp_ghosts` documents the SQL that reverses a clamp inside its module docstring, and a regex sweep reports that as a writer which does not exist; literal strings in argument *and keyword* position are read, f-strings through their literal parts, and quoted or schema-qualified table names are matched while the `beliefs_fts` and `beliefs_new` siblings are not. The check is a backstop against accidental additions and not a proof: nine of ten evasion shapes an adversarial review enumerated remain invisible to it, and both they and the two writers no static check can classify are named in the module docstring and in an explicit `UNDETECTABLE` list, with tests that fail if either record is deleted. `benchmarks/posterior_prior_grid_sweep.py --sources` measures the other half — which writers actually fire, how many of their events carry a posterior-moving valence, and how many of those land on a user-locked belief where the #1168 lock floor refuses the bump regardless of any flag.
