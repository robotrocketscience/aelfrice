### Fixed

- **An exported `GIT_DIR` no longer points the test suite at another repository ([#1707](https://github.com/robotrocketscience/aelfrice/issues/1707)).** Git hooks export `GIT_DIR` and related variables. A suite run with them set pointed every temporary-directory `git init`, and every store lookup that goes through git, at the outer repository. With `GIT_DIR` exported at a scratch repository, 129 tests failed and an `aelfrice/` store appeared in that repository's `.git`. The suite-wide sandbox fixture in `tests/conftest.py` now clears `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_COMMON_DIR`, `GIT_OBJECT_DIRECTORY`, `GIT_CEILING_DIRECTORIES`, and `GIT_DISCOVERY_ACROSS_FILESYSTEM`. The same run now passes with nothing written to the outer repository. `tests/test_git_env_scrub_1707.py` runs a second pytest with `GIT_DIR` exported and fails if the variable reaches a test.
