### Security

- **The `benchmarks` extra no longer locks three packages with open advisories ([#1730](https://github.com/robotrocketscience/aelfrice/issues/1730)).** `uv.lock` now pins `fsspec` 2026.7.0 (was 2026.2.0, [GHSA-27vj-qcqg-25rc](https://github.com/advisories/GHSA-27vj-qcqg-25rc), high), `datasets` 5.1.0 (was 4.8.5, [GHSA-379c-qx7v-6h59](https://github.com/advisories/GHSA-379c-qx7v-6h59), moderate), and `multidict` 6.9.1 (was 6.7.1, [GHSA-54p9-h82j-f925](https://github.com/advisories/GHSA-54p9-h82j-f925), moderate). `datasets` 5.1 requires `huggingface-hub` 1.31 or later, so `huggingface-hub` moves from 1.12.0 to 1.33.0, the latest 1.x release. That release requires newer `click` and `hf-xet`, so `click` moves from 8.3.3 to 8.5.0 and `hf-xet` from 1.4.3 to 1.7.0. It no longer depends on `typer`, so `typer`, `rich`, `shellingham`, `markdown-it-py`, `mdurl`, and `annotated-doc` leave the lock. Every changed package is in the `benchmarks` extra; the core install is unchanged. All three benchmark loaders (MAB, AMA-Bench, and LongMemEval) return rows under `datasets` 5.1.0.
