### Fixed

- **`aelf store split` refuses ambiguous relative onboard sessions and matches onboard folders by file identity ([#1800](https://github.com/robotrocketscience/aelfrice/issues/1800)).** An onboard run on a relative path such as `.` doesn't record the folder it ran from. The command used such a session from the work-tree root whenever at least 90% of its files were there, so a run from a subfolder that repeats its file paths at the root, such as `README.md` and `docs/index.md`, could copy a subfolder's beliefs into a marker store at the root. The command now also resolves the relative path against each marker folder in the work tree, which is a folder whose project config file holds a `[store]` table. If the session's files also reach 90% under one of those folders, its beliefs count as `no_root` and nothing is copied. A folder without a marker isn't checked. The command also compares an onboard folder to the work tree by file identity instead of by its text. Before, an absolute folder recorded in a different letter case on a case-insensitive filesystem, such as `.../MONO` for the folder `.../mono`, counted as `outside_work_tree` and none of its beliefs were copied.
