### Fixed

- **The Stop-time transcript ingest keeps its schedule when a host and a container share `turns.jsonl`, and after the file is deleted and recreated ([#1749](https://github.com/robotrocketscience/aelfrice/issues/1749)).** #1726 made the ingest counter record which `turns.jsonl` it counted, using the file's inode. A macOS host and a Docker container that share the transcripts directory see different inodes for the same file, so each read the other's counter as belonging to another file. Alternating Stops then ingested the whole live file on almost every Stop: 9 of 10 in a test. ext4 and overlayfs also give a recreated `turns.jsonl` the inode of the file just deleted, so the old count carried over. The counter now identifies the file by a digest of its first line. Every line the logger writes carries a timestamp, and turn lines carry a random turn ID, so each new file starts with a line no earlier file had. A counter written by an earlier release counts as another file, so the first Stop after you upgrade may run one extra ingest. Ingest skips statements it already stored. Separately, a byte in `turns.jsonl` that isn't valid UTF-8 no longer stops Stop-time ingest: before, it raised an error on every Stop for as long as the byte stayed in the file.
