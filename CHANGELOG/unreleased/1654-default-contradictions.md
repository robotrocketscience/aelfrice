### Documentation

- **The docs and code comments now state the defaults and mechanisms the code has ([#1654](https://github.com/robotrocketscience/aelfrice/issues/1654)).** A default-state audit found 18 statements that contradicted the code; 16 were still wrong and are fixed here, and 2 were already fixed on `main`. The onboard LLM classifier is default-on since v1.5, and `aelf onboard` falls back to the regex classifier when the SDK, the API key, or consent is missing; only `/aelf:onboard` uses the host's Task tool. Transcript ingest runs every 12 turns at `Stop`, not only at the `PreCompact` rotation. The heat-kernel scorer went back to default-off in [#1162](https://github.com/robotrocketscience/aelfrice/issues/1162). Contradiction detection ships but is off by default, `aelf doctor --detect-stale` writes edges, no command writes a `SUPERSEDES` edge between two beliefs you name, and nothing writes a `RESOLVES` edge. `[cadence]` holds the off-by-default checkpoint cadence, not feedback scoring. The temporal-spine writer and the entity-persistence demotion lane are default-on, as their resolvers return. No behavior changes.
